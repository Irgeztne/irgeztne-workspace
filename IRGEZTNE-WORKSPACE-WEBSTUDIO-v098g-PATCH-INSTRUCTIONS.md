# IRGEZTNE Workspace — Web Studio Media Placement / Render Parity v098g

## Основание

Пакет подготовлен по read-only рентгену:

`IRGEZTNE-WEBSTUDIO-MEDIA-PLACEMENT-XRAY-20260804-145758`

Базовый HEAD рентгена: `df930b48c40147a4468310d1470bf574a5a9f3f7`.

## Что показал рентген

- В активном Editor Workbench уже существуют вертикальные команды `↑` и `↓`.
- Они работают для изображения, локального видео, embed-видео и video-card.
- В редакторе уже существуют размеры `S / M / L / 100%` и выравнивание слева / по центру / справа.
- Основной подтверждённый дефект находился не в панели управления, а в цепочке вывода:
  - Editor Workbench сохранял классы `ewb-image`, `ewb-video`, `is-size-*`, `is-align-*`;
  - общий и Documentation renderer получали CSS этих классов;
  - Landing и четыре канонических шаблона Business / Blog / Portfolio / Agency использовали собственные стили и не подключали тот же media CSS;
  - поэтому в редакторе размер и положение выглядели одним образом, а в Preview / браузере / ZIP изображение или видео могло стать слишком большим или потерять выбранное выравнивание.

## Исправление v098g

- Landing подключает существующий единый generated editor-media CSS.
- Business, Blog, Portfolio и Agency подключают тот же CSS внутрь своего канонического пакета.
- Размеры и выравнивание медиа теперь имеют один контракт в:
  - Editor Workbench;
  - Preview;
  - «Открыть сайт»;
  - ZIP / опубликованной сборке.

## Что не меняется

- Не меняются шесть шаблонов и их дизайн.
- Не меняются пользовательские сайты и страницы.
- Не меняется Editor Workbench.
- Не меняются кнопки `↑ / ↓`, размеры и выравнивание — они уже существуют.
- Не меняются `main.js`, `preload.js`, Office, Chat, Account и Atlas.
- Не создаётся Git-коммит.

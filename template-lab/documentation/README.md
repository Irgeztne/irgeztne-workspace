# Documentation template lab

Third reference template for IRGEZTNE Web Studio.

Purpose:
- wide documentation / knowledge base
- sidebar navigation
- search UI
- article content
- code blocks
- callouts
- API/reference cards
- FAQ
- right table of contents
- EN/RU
- light/dark

Main slots:
- `brand.logoFallback`
- `brand.title`
- `brand.subtitle`
- `hero.codeVisual`
- `footer.links`

Images:
- Documentation usually does not need people.
- Recommended visuals: code screenshots, interface screenshots, terminal blocks, diagrams.
- Demo visuals are preview-only and should be replaced before publishing.

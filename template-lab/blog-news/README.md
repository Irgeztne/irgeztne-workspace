# Blog / News template lab

Status: first reference template package for IRGEZTNE Web Studio.

Purpose:
- real news / magazine portal
- wide layout
- independent visual identity, not Web Studio blue UI
- light / dark theme
- EN / RU localization
- RSS as a footer subscription link
- compact social share icons
- prepared slots for brand, logo, images, footer links and social links

Current package files:
- `index.html`
- `style.css`
- `metadata.json`

Main slots:
- `brand.logoFallback`
- `brand.title`
- `brand.subtitle`
- `hero.image`
- `featured.secondaryImage`
- `post.image.1`
- `post.image.2`
- `post.image.3`
- `post.image.4`
- `footer.links`
- `social.links`

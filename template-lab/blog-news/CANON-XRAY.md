# IRGEZTNE Blog / News Canon v1 — x-ray

## What the existing Template Lab package already had

- A strong editorial identity with a warm paper/red palette.
- A wide three-column front page with a lead story, secondary feed and right rail.
- Light and dark theme tokens.
- Local editorial image assets.
- A news-oriented footer and RSS concept.
- RU and EN text dictionaries.

## Why it was not yet a complete official site

- The brand returned to the Template Lab gallery.
- Most navigation links were placeholders.
- RU and EN lived inside one runtime dictionary with duplicated and conflicting keys.
- Only the front page was authored as the original editorial composition.
- Some accumulated preview layers still treated imagery as temporary technical slots.

## Why the current Web Studio output looked different

- Web Studio materialized Blog / News through the universal site/page renderer.
- The universal renderer created a simpler card grid instead of the original editorial hierarchy.
- Inner pages received generic page titles and repeated labels.
- The first visual review used gradient placeholders even though the original package contained local image assets.

## Canon v1 boundaries

- Standalone visual reference only; not integrated into Workspace.
- Four real pages in each language: Home, Articles, Topics and About.
- RU and EN are separate complete builds with no runtime language switch.
- One light/dark theme control.
- Local images only.
- Text brand treatment with no invented customer logo.
- Inner pages start with authored editorial content, not a technical Page label.
- Image markers remain future integration markers. Canon v1 does not claim that user image replacement is already connected.

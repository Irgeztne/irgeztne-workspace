# Landing / Product template lab

Fourth reference template for IRGEZTNE Web Studio.

Purpose:
- premium product landing page
- hero + product mockup
- benefits
- workflow
- proof section
- FAQ
- CTA
- EN/RU
- light/dark

Main slots:
- `brand.logoFallback`
- `brand.title`
- `brand.subtitle`
- `hero.productMockup`
- `feature.productVisual`
- `footer.links`

Images:
- Prefer product screenshots, app mockups, device visuals.
- People are optional and should only be context/non-identifiable.
- Demo visuals are preview-only and should be replaced before publishing.

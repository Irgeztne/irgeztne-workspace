# IRGEZTNE Web Studio — Template Gallery v098e

## Исправляется только каталог «Шаблоны»

1. Маленькие карточки больше не используют `srcdoc` как основной источник.
2. Каждая карточка получает реальный материализованный пакет Web Studio:
   HTML, CSS, JavaScript и локальные изображения.
3. Все шесть мини-превью показываются в едином тёмном состоянии через уже
   существующий контракт `?theme=dark`.
4. Большое Preview остаётся интерактивным и по-прежнему поддерживает обе темы.
5. Светлая оболочка каталога получает нормальный бело-голубой фон вместо
   серо-бетонного полупрозрачного блока.
6. Внутри одной сессии материализованные адреса кэшируются, чтобы не создавать
   шесть новых папок при каждом переключении светлой/тёмной темы Workspace.

## Не изменяется

- содержимое шести шаблонов;
- Landing и Documentation;
- Business, Blog, Portfolio и Agency;
- страницы, изображения, RU/EN;
- большой Preview и «Открыть в окне»;
- пользовательские сайты;
- main.js, preload.js;
- Editor Workbench;
- экспорт и публикация.

## Отдельно после завершения шаблонов

Вертикальное перемещение видео вверх/вниз в Editor Workbench не входит в этот
проход и должно рассматриваться отдельным рентгеном владельца блоков.

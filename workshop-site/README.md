# Workshop Site v0.1

Статическая основа публичной Мастерской пакетов.

Назначение:
- публичная витрина шаблонов, тем, блоков, виджетов и ассетов;
- позже открывается из приложения во встроенном браузере;
- не заменяет старую локальную Мастерскую, а становится внешним домом для каталога.

Текущее состояние:
- HTML/CSS/JS без backend;
- демо-карточки;
- фильтры, поиск, модальное окно пакета;
- демо-форма добавления пакета.

Позже:
- Cloudflare Pages;
- Cloudflare Workers API;
- D1 база;
- авторы, аккаунты, модерация, реальные пакеты.

# IRGEZTNE Workspace — Web Studio v094a

Этот пакет устанавливается поверх уже принятой цепочки:

1. `v092d-cumulative-correction`
2. `v092e-logo-identity-correction`
3. `v094a-wide-templates-editor-completion`

Пакет не содержит базу данных, профиль, пользовательские сайты, медиа или
настройки Workspace. Коммит автоматически не создаётся.

## Что исправлено

- Все шесть официальных шаблонов открываются в широкоформатном виде.
- Галерея, созданный сайт, Preview, браузер и ZIP используют один product
  renderer вместо старых страниц `template-lab`.
- Landing, Portfolio, Documentation, Business / Product, Agency / Studio и
  Blog / News проверяются одним контрактом.
- Portfolio и Agency получили полноценные широкие домашние композиции.
- Выбор и просмотр карточки шаблона больше не меняет сохранённый шаблон сайта.
- Язык сохраняется в самом сайте: RU-сайт не становится EN при переключении
  интерфейса Web Studio.
- Редактор растёт вместе с документом и передаёт прокрутку внешней оболочке.
- Выделенный фрагмент текста можно превратить в отдельный P/H1/H2/H3/цитату,
  не меняя весь исходный абзац.
- Выбранные изображение и видео можно перемещать выше или ниже между соседними
  блоками.

## Установка

Остановите приложение, затем выполните:

```bash
cd ~/Загрузки/irgeztne-workspace-main || exit 1

cp -a ~/Загрузки/irgeztne-workspace-main \
  ~/Загрузки/irgeztne-workspace-main-backup-before-v094a

unzip -o \
  ~/Загрузки/IRGEZTNE-WORKSPACE-WEBSTUDIO-v094a-wide-templates-editor-completion.zip \
  -d ~/Загрузки/irgeztne-workspace-main

npm start
```

## Контрольная проверка

1. В разделе «Шаблоны» откройте по очереди все шесть карточек.
2. Убедитесь, что каждая открывается широкоформатно и без старой компактной
   страницы `template-lab`.
3. Создайте тестовый сайт из Portfolio и Agency и сравните галерею, Preview,
   обычное открытие в браузере и экспортированный ZIP.
4. В редакторе выделите одно слово внутри абзаца и нажмите `H2`: должен
   измениться только выделенный фрагмент.
5. Добавьте изображение или видео, откройте кнопку `⋯` и проверьте стрелки
   перемещения вверх и вниз.
6. Сделайте длинную страницу и проверьте, что холст растёт без собственной
   вложенной полосы прокрутки.
7. Проверьте светлую и тёмную тему, затем RU и EN на отдельном тестовом сайте.

После визуальной приёмки можно делать единый коммит Web Studio.

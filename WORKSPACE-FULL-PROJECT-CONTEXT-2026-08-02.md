## 5. Git и контрольные точки

Текущий архив был создан без `.git`, поэтому по нему нельзя честно зафиксировать:

- текущий HEAD;
- чистоту рабочего дерева;
- наличие локальных незакоммиченных изменений;
- точную последовательность коммитов после 14 июля.

HEAD `a0f8fad`, указанный в старом MD, является исторической точкой на 14 июля и не должен называться текущим без проверки в живой папке.

Перед каждым новым изменением в живом проекте выполнять:

```bash
cd ~/Загрузки/irgeztne-workspace-main || exit 1
git status --short
git rev-parse --short HEAD
git log -1 --oneline
```

После принятого результата:

1. проверить diff;
2. выполнить релевантные тесты;
3. провести ручную визуальную приёмку;
4. создать отдельный Git-коммит;
5. только затем считать участок контрольной точкой.

ZIP не заменяет Git-коммит, а Git-коммит не заменяет внешний контрольный снимок.

Принятые правила:

1. Все шесть шаблонов должны быть широкоформатными и восприниматься как один официальный комплект Web Studio.

8. Появление страницы в header/sidebar/footer управляется отдельно и явно.
9. Preview, браузер, ZIP и publish должны показывать одну и ту же сгенерированную сборку.
10. Не создавать второй каталог Templates.
11. Не создавать второй production-рендерер.
12. Не добавлять новые официальные шаблоны до приёмки текущих шести.

## 14. Текущий дефект темы и белой вспышки

### Ручное наблюдение пользователя

Белая вспышка остаётся:

- при переходах между страницами Documentation в Premium Preview;
- при переходах между HTML-страницами открытого сайта;
- слабее в обычном браузере, сильнее внутри Preview/Premium;
- в браузерном сценарии вспышка также наблюдалась при ручном переключении темы.

### Подтверждённые причины в активном коде

1. Сгенерированный `<html>` создаётся с `data-theme="light"`.
2. Сгенерированный `<body>` также создаётся с `data-theme="light"`.
3. Скрипт `v096c` позже определяет сохранённую тему, но исходная разметка всё равно принудительно светлая.
4. Обычный Preview iframe начинается с `src="about:blank"`.
5. `.ir-site-studio-v5-preview-frame` имеет белый фон.
6. Для `iframe[src="about:blank"]` отдельно задан белый фон.
7. Большой template/Premium iframe также имеет белый фон.
8. При materialized package новый HTML-документ и внешний CSS загружаются отдельными ресурсами; до применения нормального фона возможен белый первый кадр.

Это общий механизм, а не дефект одного Documentation.

### Статус `v096c`

`IRGEZTNE-WORKSPACE-WEBSTUDIO-v096c-theme-prepaint.zip` был установлен и проверен пользователем.

Результат:

> **Не принят как исправление белой вспышки.**

Код `v096c` может присутствовать в активной папке, но его наличие не означает, что задача закрыта.

Тест:

```text
scripts/test-webstudio-theme-prepaint-v096c.js
```

проходит, но проверяет только исполнение JavaScript в искусственном DOM. Он не проверяет:

- первый реальный кадр iframe;
- `about:blank`;
- загрузку CSS;
- переход между физическими HTML-файлами;
- визуальный кадр внешнего браузера;
- Premium Preview.

Поэтому проход этого теста не является доказательством отсутствия вспышки.

4. Совместима ли она с текущим route `codehub`?
5. Какие данные она хранит?
6. Что будет затронуто восстановлением?
7. Какой checkpoint нужен?

### Шаг 5. Остановиться

Не устанавливать найденный CodeHub автоматически.

Сначала показать пользователю:

- найденную версию;

- узкий план восстановления;
- список изменяемых файлов;

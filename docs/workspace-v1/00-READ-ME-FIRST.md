## Назначение этого комплекта

Документы фиксируют продуктовую архитектуру Workspace,
обсуждённую 6 августа 2026 года.

Главная цель — не копировать LibreOffice и не выпускать
приложение ради формального релиза.

Workspace должен стать полезной локальной рабочей
системой с законченными маршрутами:

`проект → задача → исходный материал → нужный инструмент
→ сохранённый результат`

Пользователь не должен уходить на случайные внешние сайты
ради элементарной обработки документов, данных,
изображений или других рабочих материалов.

## Статус документов

Это подробная проектная основа, но ещё не разрешение
писать код.

Перед реализацией необходимо:

- проверить формулировки;
- провести фактическую инвентаризацию существующего кода;
- определить runtime-владельцев;
- принять границы каждого этапа;
- подготовить отдельную матрицу приёмки.

## Главное правило

Не смешивать в одном патче:

- интеграцию Мастерской в Web Studio;
- перестройку главной Workspace;
- развитие раздела Tools;
- реализацию Tasks;
- исправления существующих модулей.

# Workspace Home v1 — Product Specification Baseline

## 1. Назначение главной

Главная Workspace не обязана зеркально повторять весь
список разделов.

Она должна помогать:

- быстро продолжить работу;
- увидеть ближайшие действия;
- создать нужный объект;
- открыть последний материал;
- перейти к реальному рабочему маршруту.

## 2. Текущая ситуация

На главной сейчас есть отдельные карточки:

- Шаблоны;
- Мастерская.

После интеграции обе возможности будут находиться внутри
Web Studio.

Поэтому их роль на главной должна быть переосмыслена.

## 3. Важное ограничение

Не удалять карточки немедленно.

Сначала:

1. завершить интеграцию Мастерской в Web Studio;
2. проверить прямые переходы;
3. принять новую структуру главной;
4. только затем менять карточки.

## 4. Основные рабочие пространства

Предварительный набор самостоятельных направлений:

- Files;
- Projects;
- Office;
- Notes;
- Tasks;
- Tools;
- Web Studio;
- Chat.

## 5. Полезные блоки главной

Вместо искусственного создания новых модулей можно
использовать динамические блоки:

### Продолжить работу

- последний проект;
- последний документ;
- последний сайт;
- текущая задача.

### Работа сегодня

- просроченные задачи;
- задачи на сегодня;
- ближайшие сроки;
- задачи в работе.

### Быстро создать

- проект;
- документ;
- заметку;
- задачу;
- сайт.

### Web Studio

- открыть последний сайт;
- выбрать шаблон;
- открыть Мастерскую;
- открыть предпросмотр.

### Инструменты

- недавно использованные;
- избранные;
- рекомендуемые по текущему контексту.

## 6. Не делать

- не добавлять карточки ради заполнения сетки;
- не показывать недоступные функции;
- не обещать будущие модули;
- не дублировать один раздел несколькими крупными
  карточками без необходимости.

## 7. Приёмка будущей главной

Главная считается полезной, если пользователь может:

- продолжить недавнюю работу;
- увидеть актуальные задачи;
- создать основной рабочий объект;
- перейти в Web Studio;
- вызвать нужный инструмент;
- не искать одну и ту же функцию в нескольких местах.

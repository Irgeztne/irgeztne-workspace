# IRGEZTNE Data Platform v0.2

Общий локальный Data Core для Atlas, Workspace и Economy Widget. Версия сохраняет источники v0.1 и добавляет настоящие исторические ряды, строгий provenance, устойчивый кэш и потребительские slices.

## Источники

- World Bank: ВВП и инфляция, исторические годовые наблюдения.
- ECB: официальные дневные reference FX; это не live/tick market quote.
- BIS: история ключевых ставок там, где ряд доступен.

Если источник недоступен, последнее подтверждённое наблюдение сохраняется как `cached`; ноль и фиктивная «свежая» точка не создаются.

## Команды

```bash
npm run refresh
npm test
npm start
```

Локальный API: `/v1/data`, `/v1/series/...`, `/v1/entity/.../summary`, `/v1/widget/economy`, а также совместимые `/api/health`, `/api/data`. Принудительное обновление выполняется CLI; HTTP refresh защищён локальным capability-заголовком.

UI Workspace обращается только к локальному Data Platform или к поставленному официальному snapshot и никогда напрямую к внешним поставщикам.

В Electron локальный сервис запускается вместе с Workspace и хранит обновляемый snapshot в пользовательском каталоге приложения. Ручной запуск нужен только для автономной разработки Data Platform.

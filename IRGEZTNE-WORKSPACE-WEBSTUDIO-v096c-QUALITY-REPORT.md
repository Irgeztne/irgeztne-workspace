# IRGEZTNE Workspace / Web Studio v096c — Quality Report

## Объём

Исправлен единый владелец рендера официальных шаблонов:

- `Landing`;
- `Documentation`;
- общий runtime темы для остальных официальных шаблонов.

## Причина дефекта

Generic renderer создавал `<body data-theme="light">`, а сохранённая тёмная
тема применялась только отложенным `assets/js/site.js`. Браузер успевал
отрисовать светлый фон. Дополнительно общий CSS анимировал фон тела в течение
`0.18s`, что усиливало эффект при ручном переключении.

## Исправление

- добавлен синхронный pre-paint theme boot в `<head>`;
- тема читается из `?theme=` или `localStorage` до первого отображения;
- значение сразу записывается в корневой `<html>`;
- сразу после открытия `<body>` тема синхронизируется до разметки страницы;
- runtime поддерживает одинаковое состояние `<html>` и `<body>`;
- ссылки между локальными HTML-страницами получают текущую тему;
- убрана анимация фона тела через светлое состояние.

- фон тела больше не анимируется из светлого состояния.

# IRGEZTNE Live API v1 Foundation

This folder is the first server-side foundation for IRGEZTNE Workspace 1.0.0.

The desktop app stays local-first and does not require an IRGEZTNE account for normal work.

Live API adds optional online functions:

- Rooms / Chat v1
- Private Analytics v1

No accounts, no full sync, no video, no marketplace in this stage.

## Files

```text
live-api/
  worker.js
  wrangler.toml.example
  README.md
```

## Endpoints

### Health

```http
GET /health
GET /v1/health
```

### Rooms / Chat v1

```http
POST /v1/rooms
GET  /v1/rooms/:roomId
POST /v1/rooms/:roomId/messages
GET  /v1/rooms/:roomId/messages
```

Create room response returns:

```json
{
  "ok": true,
  "room": { "id": "room_..." },
  "token": "secret-token"
}
```

The token is stored locally by the app and used as:

```http
Authorization: Bearer <token>
```

### Analytics v1

```http
POST /v1/analytics/sites
POST /v1/analytics/events
GET  /v1/analytics/sites/:siteId/summary
```

Create analytics site response returns:

```json
{
  "ok": true,
  "site": { "id": "site_..." },
  "token": "secret-token"
}
```

## Privacy direction

Analytics v1 is privacy-first.

It does not store:

- raw IP addresses
- full user agent strings
- names
- emails
- advertising IDs
- fingerprint profiles

It stores:

- page path
- event type
- referrer domain
- approximate device type
- browser family
- approximate country from Cloudflare metadata when available
- event time
- optional session id generated by the website, not a personal identity

## Storage

For production, bind Cloudflare KV as:

```text
IRGEZTNE_LIVE_KV
```

`worker.js` has an in-memory fallback only for local/dev testing. Production should use KV or later D1/Queues.

## First local test idea

After deployment, test health:

```bash
curl https://YOUR_WORKER_URL/health
```

Create a room:

```bash
curl -X POST https://YOUR_WORKER_URL/v1/rooms \
  -H "Content-Type: application/json" \
  -d '{"title":"Test room","projectId":"local-project"}'
```

Send a message:

```bash
curl -X POST https://YOUR_WORKER_URL/v1/rooms/ROOM_ID/messages \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer ROOM_TOKEN" \
  -d '{"authorName":"Tom","text":"Hello from IRGEZTNE"}'
```

Create analytics site:

```bash
curl -X POST https://YOUR_WORKER_URL/v1/analytics/sites \
  -H "Content-Type: application/json" \
  -d '{"name":"My Web Studio site","origin":"https://example.com"}'
```

Track event:

```bash
curl -X POST https://YOUR_WORKER_URL/v1/analytics/events \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer SITE_TOKEN" \
  -d '{"siteId":"SITE_ID","type":"page_view","path":"/","referrer":"https://google.com"}'
```

Get summary:

```bash
curl "https://YOUR_WORKER_URL/v1/analytics/sites/SITE_ID/summary?token=SITE_TOKEN"
```

# IRGEZTNE Workspace

**IRGEZTNE Workspace** is a local-first desktop application built with Electron for everyday work, notes, projects, offline backup, and static website creation.

## Release Status — v1.0.0

Version **1.0.0** is available for Linux (`.deb`, `.AppImage`), Windows (`.exe`), and macOS (`.dmg`) on [GitHub Releases](https://github.com/Irgeztne/irgeztne-workspace/releases/tag/v1.0.0).

## Workspace Modules

- **Available in 1.0.0:** Files, Projects, Office, Notes, Tasks, Tools, Built-in Browser, Web Studio (with 6 templates and 4 publishing options: Local ZIP, Netlify, Cloudflare Pages, Own Hosting SFTP/FTPS), and Workspace Backup & Migration.
- **Coming Soon:** Workshop, Chat, and IRGEZTNE Account.

## Documentation & Security

- **Docs:** `docs/release/00-READ-ME-FIRST.md` and [://irgeztne.com](https://irgeztne.com/docs.html).
- **Security:** Do not commit account secrets or private backups.
